mit-ayiti.net Migration Report

Measured results from moving the MIT-Haiti open educational resource platform off WordPress. Four page pairs were tested on both sites under a simulated Haitian mobile connection.

Background

mit-ayiti.net publishes teaching materials in Haitian Creole for teachers across Haiti. Most readers arrive on a phone over mobile data. Two independent real world samples put a typical Haitian mobile connection near 7 Mbps.1 Internet penetration in the country was 39.3% as of October 2025.2

All testing used Google Lighthouse 12.8.2 against identical URLs on both sites, since the migration preserved the existing URL structure. Figures below are medians of three runs on the simulated Haitian mobile profile.3

Page Response Speed (TTFB and FCP)

First Contentful Paint improved on all four pages, by between 48% and 55%. Time to First Byte improved by between 80% and 93%. The old site generated every page on each request and sent Cache-Control: no-store, no-cache, so no response was reusable. The new site serves pre-rendered pages from a CDN edge cache.

Page TTFB before TTFB after FCP before FCP after
Home 0.95s 0.07s 1.59s 0.73s
Resource library 0.52s 0.10s 1.57s 0.71s

Variance narrowed as well. Home page TTFB samples on the old site ranged from 0.89s to 2.03s across the full test set, against 0.04s to 0.14s on the new site.

Page Size

Transfer size fell on all four pages. The two largest reductions were the blog index at 86% and the home page at 60%.

Page Requests before Requests after Transfer before Transfer after Change
Home 138 60 2,520 KB 1,007 KB 60% smaller
Resource library 92 77 1,419 KB 1,193 KB 16% smaller
A resource page 133 89 4,579 KB 3,978 KB 13% smaller
Blog index 77 48 6,062 KB 854 KB 86% smaller

The resource page embeds the Google Drive document viewer, which accounts for roughly 9 MB of third party code. That embed is present on both sites, so it is held constant across the comparison rather than counted as an improvement.5

SEO and Accessibility

Lighthouse SEO reached 100 on all four pages. The old site failed the same two audits sitewide, for a missing meta description and for links that could not be crawled. Both are resolved on the new site.

Home 85 100 82 92
Resource library 83 100 91 96
A resource page 85 100 88 97
Blog index 83 100 91 96

Accessibility scores improved on all four pages. These are Lighthouse automated checks, which cover a subset of WCAG criteria and do not replace manual testing.

Notes on the measurements

  1. SpeedOf.Me in browser tests report a median of 6.9 Mbps and 101 ms latency for Haiti. Speedgeo puts Digicel's mobile average at 7.1 Mbps. Ookla's Speedtest median is higher at 16.08 Mbps. The lower figure was used. Throttling was applied at 7 Mbps and 100 ms round trip time with a 4x CPU slowdown, simulated from the United States rather than measured in Haiti.
  2. DataReportal, Digital 2026, Haiti.
  3. Google Lighthouse 12.8.2 using Lantern simulated throttling, the same method used by PageSpeed Insights. 40 runs across four page pairs. The old site is the WordPress installation currently serving the public. The new site is the deployed replacement.
  4. SEO and Best Practices were measured against a build configured identically to production. Pre-launch environments carry a hosting platform header that instructs search engines not to index them, which suppresses the SEO score for reasons unrelated to the site. Speed and transfer size figures come from the deployed site.
  5. Figures include third party resources, since those are downloaded by readers. The old site also loads Google Analytics.
