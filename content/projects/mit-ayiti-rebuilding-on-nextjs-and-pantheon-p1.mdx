    tagline: Classroom materials in the language students actually speak
    background: white
    richText: >
      <p>The Platform Ayiti Project provides classroom material in Haitian Creole
      for all ages and all subjects, created by Haitian teachers, for Haitian
      teachers. In Haiti, the official language for schools is French. But
      virtually 100% of the population speaks Haitian Creole as their native
      language, and it is a part of the cultural identity.</p>

      <p>Platform Ayiti gives teachers a place to share resources and collaborate.
      The site has been successful for ten years. The challenge was a major
      upgrade to improve its functionality and its performance.</p>
  - type: MainSection
    title: The Approach
    tagline: Migrate from a website, to a modern web application
    background: gray
    richText: >
      <p>We rebuilt their web site into a modern progessive web application.  We added 
      features that allowed the user of the site to not only find materials, but to 
      curate their favorite sources and share lists with other users.  We moved from a 
      content publishing model to a content platform, a real teaching library.</p>

      
      Utilizing Next.js, Pantheon P1, and Google Firebase, we developed a modern
      progressive web application.  This provided a faster and more end user centric experience.  </p>

      <dl class="verdict-list">
        <div data-verdict="rejected">
          <dt>Option 01</dt>
          <dd>Keep WordPress on DreamHost and clean up the plugins.</dd>
        </div>
        <div data-verdict="rejected">
          <dt>Option 02</dt>
          <dd>Move the WordPress site to Pantheon.</dd>
        </div>
        <div data-verdict="chosen">
          <dt>Option 03</dt>
          <dd>Rebuild on Next.js, Pantheon P1 and Firebase: static-first pages
          rendered on the server, Firebase for teacher accounts and saved
          lists, and P1's visual editor for the people who edit content.</dd>
        </div>
      </dl>

      <p>We chose option three. We wanted the site to be really, really fast:
      to take advantage of local storage and caching as much as possible, and
      to be super optimized. With a multi-plugin architecture, it's hard to
      fine-tune what gets delivered to the browser. By building everything
      from scratch, we could maximize the optimization.</p>
  - type: MainSection
    title: The Stack
    tagline: Server-rendered, edge-cached, and easy to edit
    background: white
    richText: >
      <ul>
        <li><strong>Next.js.</strong> Static-first pages rendered on the
        server and served from the CDN edge, with as little client-side
        JavaScript as possible.</li>
        <li><strong>Pantheon P1.</strong> Content and media, with a visual
        editor built on the open-source Puck editor and Tiptap.</li>
        <li><strong>Firebase.</strong> Firebase Auth and Firestore for teacher
        accounts and saved lists, with one document per user.</li>
      </ul>
  - type: MainSection
    title: How We Built It
    tagline: Decisions first, then code
    background: gray
    richText: >
      <p>A few decisions shaped the build:</p>

      <ul>
        <li>We kept every primary URL in exactly the same shape, so there was
        nothing to redirect.</li>
        <li>We rebuilt faceted search as a small index filtered in the
        browser, which search engines can now crawl.</li>
        <li>Saved lists are cached and work offline, and teachers reorder them
        with up and down arrows, so keyboard and screen-reader users can
        manage them too.</li>
        <li>We dropped Polylang and the stack of security plugins.</li>
      </ul>

      <h4>How we used AI</h4>

      <ul>
        <li>Integrated with the WordPress APIs and codebase.</li>
        <li>Audited the source site's code and content structure.</li>
        <li>Built deterministic migration scripts to migrate the content.</li>
        <li>Built repeatable Playwright test suites.</li>
      </ul>
