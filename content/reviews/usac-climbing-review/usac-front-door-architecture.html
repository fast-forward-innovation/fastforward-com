A new front door, wired into the platforms USA Climbing already runs

  1. Sign in once at usaclimbing.orgSingle sign-on, linked to Sport80
  2. See SafeSport and background check status on the dashboardWeb services read from Sport80
  3. Open the judge course in the same tabLTI 1.3 launch into Moodle, with no pop-up
  4. Pass the examLTI Assignment and Grade Services returns the score
  5. Certification updates automaticallyWeb services write it back to Sport80

Five steps, one site, one sign-in.

Target architecture proposed by Fast Forward. Single sign-on and web service coverage depend on what Sport80 and Vertical-Life expose, and will be confirmed in discovery. Where an API is missing, the front door falls back to a deep link or an embed. Google sync uses a service account with read access to the specific files USA Climbing chooses to publish.
